✈️ Flight Delay Prediction using Machine Learning
📌 Description

This project predicts flight delays using historical aviation data and machine learning algorithms.
By analyzing factors such as airline, departure time, origin, destination, and weather conditions, the system predicts whether a flight will be delayed or on time.

It useses xg  boost as training model and also useses random forset.

This project is built for learning purposes and demonstrates a complete end-to-end ML workflow.

🎯 Objectives

Understand real-world data preprocessing

Build a machine learning prediction model

Classify flight delays accurately

Gain hands-on experience with ML tools

🧠 Problem Type

Classification: Delayed / Not Delayed

Regression (Optional): Delay duration in minutes

📂 Dataset

Source: Public Flight Delay Dataset (Kaggle)

Format: CSV

Key features:

Airline

Flight number

Origin & destination

Scheduled departure

Delay time
